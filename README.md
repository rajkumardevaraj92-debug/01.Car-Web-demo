\# 🏎️ Super Car Showcase Web Application



A modern, responsive web application showcasing the world's most incredible super cars with a sleek, dark-themed UI.



\## ✨ Features



\- 🔥 Dynamic car display with detailed specifications

\- 🎨 Modern dark theme with gold accents

\- 📱 Fully responsive design

\- 🚀 Smooth animations and transitions

\- ⚡ Docker containerized for easy deployment

\- 🔄 CI/CD pipeline with Jenkins



\## 🚀 Quick Start



\### Using Docker

```bash

\# Build the image

docker build -t supercar-app .



\# Run the container

docker run -p 8080:80 supercar-app



\# Or use docker-compose

docker-compose up -d
